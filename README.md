Ed25519 address helper — Solana-shaped prefix.

## Features

- SOL path m/44'/501'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd ed25519-addr
cargo build --release
./target/release/ed25519-addr --help
```

## Tests

```bash
cargo test
```
